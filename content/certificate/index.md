# Certificate

우리는 프로그래밍 개발자이다. 개발자로서 실력은 문제 해결 능력과 개발 능력이겠지만, 이는 프로젝트로만 보여주기에는 어려운 경우가 많다. 그렇기 때문에 우리는 자격증 시험을 치루고, 이것을 빌미로 내가 얼마나 잘하고 잘 아는지 보여준다.

여기 폴더에서는 내가 자격증을 따기 위해 공부했던 과정과 공부한 내용을 적는 곳으로 보면 되겠다. 이론에 대한 지식은 각 분야에 맞게 정리되어 있지만, 이 폴더는 시험을 위한 과정으로만 보면 될 것 같다.
