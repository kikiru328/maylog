## 문제 분석하기

- 무작정 코드를 작성하기 보다는 문제 분석에 시간을 쓴다

1. 문제를 쪼개서 분석한다.
2. 제약사항을 파악하고 테스트 케이스를 추가한다
3. 입려ㅛㄱ값을 분석한다
4. 핵심 키워드를 파악한다.
	1. 최적의 해 = 너비우선탐색 BFS
	2. 정렬된 상태 = 이진탐색, 파라메트릭 탐색
	3. 최단경로 = 다익스트라 등
5. 데이터 흐름이나 구성 파악
	1. 삽입과 삭제가 빈번 = 힙
	2. 50개 미만 입력값이 더러울경우 하드 코딩
	3. 데이터간 격차가 크면 인덱스느 불필요

## 키워드
- 스택
	- 쌍이 맞는지
	- 최근
		- 무언가를 저장하고 반대로 처리해야 할 때
		- 데이터의 조합이 균형을 이뤄야 할 때
		- 알고리즘이 재귀 특성을 가질 때
		- 최근 상태를 추적할 때
- 큐
	- 순서대로
	- ~대로 동작한다
	- 스케줄링
	- 최소시간
		- 특정 조건에 따라 시뮬레이션할 때
		- 시작 시점에서 목표지점까지 최단 거리
- DFS
	- 모든 경로
		- 메모리 사용량이 제한적
		- 백트래킹 문제
- BFS
	- 최적
	- 최소단계
	- 레벨순회
	- 네트워크 전파
		- 시작 지점부터 최단 경로나 최소 횟수를 찾아야 할 때
- 백트래킹
	- 조합
	- 순열
	- 부분집합
		- 조합 및 순열
		- 특정 조건을 만족하는 부분 집합
- 최단 경로
	- 최단경로
	- 최소시간
	- 최소 비용
	- 트래픽
	- 음의 순환
	- 단잃 추발점 경로
		- 다익스트라: 특정 지점에서 나머지 지점까지 가는 최단 경로
		- 벨만-0포드: 음의 순환 탐지, 음의 가중치를 가진 그래프에서 최단 경로

O(N^2) - 3,000~5,000
O(NlogN) - 1,000,000

## SET
remove : 특정원소 제거 (없으면 에러)
discard: 특정원소 제거 (없어도 무관)
clear: 모든 원소 제거
union: 합집합
	set1 |= set2
	set1.union(set2)
intersection: 교집합
	set1.intersection(set2)
	set1 &= set2
difference: 차집합
	set1.difference(set2)
	set1 -= set2
