# 클린 아키텍처

클린 아키텍처(Clean Architecture)는 **소프트웨어의 유연성, 유지보수성, 테스트 용이성**을 극대화하기 위해 고안된 **아키텍처 설계 원칙**이다. 복잡한 시스템에서 빛을 보이는데, `"무엇이 변경되어도 핵심 비즈니스 로직은 영향을 받지 않도록"` 구조화하는 것이 핵심이다.

클린 아키텍처는 Uncle Bob (로버트 C 마틴)이 제안한 설계 패턴이다.  
그리고 이 원칙을 핵심으로 설계해야 한다

> "의존성은 안쪽으로. Dependency Rule"

## 클린 아키텍처의 기본 구조

클린 아키텍처는 기본적으로 계층 구조를 따른다.
