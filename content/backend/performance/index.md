# Performance

성능 문제는 단순한 속도가 아니라 서비스의 안정성과 확장성, 비용 효율성과 직결됩니다.    
이곳에서는 프로그래밍 방식, 병목 원인 분석, 비동기 설계 전략 등 성능을 구조적으로 이해하고 개선하기 위한 내용을 정리해 나갈 예정입니다.
